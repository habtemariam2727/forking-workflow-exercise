# Contributing Guidelines

Thank you for contributing to this template software project repository.

## Questions and Issues

If you have a question, find a bug, or want to suggest an improvement, please first check the existing issues.

If no relevant issue exists, open a new issue and describe your question or proposed change clearly.

## Making Changes

Before making changes, open an issue to describe what you plan to do.

Then:

1. Create a new branch from `main`.
2. Make your changes.
3. Commit your changes with a clear commit message.
4. Reference the related issue in your commit message.
5. Push your branch to GitHub.

## Pull Requests

When your changes are ready:

1. Create a pull request to the `main` branch.
2. Use a clear title and description.
3. Reference the related issue.
4. Wait for review and address comments if needed.
